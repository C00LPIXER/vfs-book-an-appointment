VFS accounts

The login watcher rotates through these: every sweep signs in with the least recently used account, through its own proxy (= its own IP) and browser profile, then closes the browser. IMAP = that account's Gmail App Password so the bot reads its own OTP (user defaults to the email). Proxy: socks5://user:pass@host:port or http://…; leave empty to use the machine's IP.
